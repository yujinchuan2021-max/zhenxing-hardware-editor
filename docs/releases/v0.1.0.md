# 枕星配置修改器 v0.1.0

首个独立版本，将枕星图吧AI助手的配置修改器整理为单独的 Windows WinUI 3 应用。
支持 Windows 10 2004（版本 19041）及以上版本与 Windows 11。

## 首发功能

- CPU、主板、显卡、内存、显示器、硬盘六类硬件展示名称编辑。
- 内置 96 个真实型号或产品系列，支持品牌、型号搜索和自定义名称。
  型号库包含 CPU 22、主板 13、显卡 26、内存 12、显示器 10、硬盘 13 条。
  每条保留官方厂商来源，资料核对日期为 2026-10-06，搜索可离线使用。
- 六类硬件卡片随窗口宽度排列为三列、两列或一列；选择类别后集中编辑。
  支持多设备选择，应用前可以查看整个展示配置预览。
- 支持跟随系统、浅色和深色主题。
- 可保存本地展示配置；受支持的 Windows 名称同步包含原值备份、写入后回读
  校验和一键恢复。恢复失败的条目保留备份，便于重试。

## 修改范围

本工具修改展示名称，真实硬件、固件、容量、频率和性能保持不变。

CPU 和主板可同步 Windows 注册表中的显示字段；显卡、显示器和硬盘可同步所选
设备的 Windows 友好名称。这些显示字段不改变设备真实型号，固件、WMI 或其他
检测软件仍可能显示真实硬件名称。系统重启或驱动更新也可能重置 Windows 名称。

**内存仅保存在本工具的本地展示配置中**，不修改内存 SPD、固件或 WMI 型号。
未检测到的类别可以保存本地展示配置，不会写入系统。

型号库是整理后的展示名称预设，不代表实时库存、销售排名或硬件兼容性。

## 下载与使用

从 [v0.1.0 发布页](https://github.com/yujinchuan2021-max/zhenxing-hardware-editor/releases/tag/v0.1.0)
下载 `ZhenxingHardwareEditor-0.1.0-win-x64.zip` 和同名 `.zip.sha256` 校验文件。
完整解压后运行 `ZhenxingHardwareEditor.exe`，系统会请求管理员权限。

便携包包含 .NET 和 Windows App SDK 运行时，不需要安装主版枕星图吧AI助手。
本地展示配置与系统原始字段备份默认保存在
`%LOCALAPPDATA%\ZhenxingHardwareEditor`，首次使用请保留该目录中的备份。

1. 选择硬件卡片和具体设备，搜索预设型号或填写展示名称。
2. 查看展示配置预览，选择是否同步受支持的 Windows 显示名称，再应用修改。
3. 需要还原时使用“一键恢复”；失败的恢复项可在设备重新连接后重试。

取消同步仅保存本地展示配置，不写入 Windows 名称；当前独立版启动时仍会请求
管理员权限。
