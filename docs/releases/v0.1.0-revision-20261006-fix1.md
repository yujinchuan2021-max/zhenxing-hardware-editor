## 修订内容

- 编辑界面分别显示本地保存目标与“当前 Windows 名称”。加载已保存配置时，目标名称
  不再代替实际读取的 Windows 名称；Windows 名称被驱动重置后，刷新设备可看到当前值，
  本地保存目标仍保留。保存目标不代表已完成系统同步。
- 保存按钮、确认提示和结果说明明确区分本页配置与系统名称同步。系统同步结果仅以
  受支持名称字段的写入与回读校验为准，不验证第三方检测软件的显示结果。
- 六类硬件分别说明作用范围。独立版提供配置编辑与预览，没有硬件盘点页。

## 名称作用范围

本地配置只用于本页的编辑和预览，其他软件不会套用本页配置。

| 类别 | 可同步的 Windows 名称 | 本地配置与限制 |
| --- | --- | --- |
| CPU | 单处理器所有逻辑核心的注册表名称字符串 | 展示厂商仅本地保存；多处理器或拓扑未知时仅本页配置与预览；CPUID 型号不变 |
| 主板 | 注册表中的主板名称和厂商显示字符串 | 固件 SMBIOS 中的真实主板信息不变 |
| 显卡 | 选中设备的 PnP `FriendlyName` | 展示厂商仅本地保存；驱动报告的型号与显存不变 |
| 内存 | 不同步 | 仅本页配置与预览；SMBIOS 型号、SPD、容量与频率不变 |
| 显示器 | 选中设备的 PnP `FriendlyName` | 展示厂商仅本地保存；EDID 型号、尺寸与分辨率不变 |
| 硬盘 | 选中设备的 PnP `FriendlyName` | 展示厂商仅本地保存；控制器报告的型号、容量与序列号不变 |

未检测到的类别只保存本地配置，不写入系统。PnP `FriendlyName` 是设备管理器友好名称；
其他软件是否显示别名取决于其读取的数据源。第三方检测软件重新扫描后，仍可能从
CPUID、固件、驱动、EDID 或磁盘控制器获得真实型号。重启或驱动更新也可能重置
Windows 名称，不能将本页预览视为其他软件的显示结果。
